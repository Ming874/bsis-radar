# ESP32 ⇄ 網頁 通訊協定

Radar A 的 ESP32 與網頁之間用**一行一筆的純文字**溝通：`鍵=值` 以空白分隔，每行以 `\n` 結尾。
同一套指令也可以從 USB 序列埠（115200 bps）輸入，方便不用手機就能測試與校正。

## 傳輸層：藍牙 BLE（Nordic UART Service）

| 項目 | 值 |
| --- | --- |
| 裝置名稱 | `RadarA-ESP32` |
| Service | `6E400001-B5A3-F393-E0A9-E50E24DCCA9E` |
| RX（網頁 → ESP32，Write） | `6E400002-B5A3-F393-E0A9-E50E24DCCA9E` |
| TX（ESP32 → 網頁，Notify） | `6E400003-B5A3-F393-E0A9-E50E24DCCA9E` |
| MTU | 247（ESP32 要求；實際值由手機決定） |

- ESP32 依協商到的 MTU 把一行切成多個通知（每段最多 MTU − 3 位元組），網頁用 `\n` 重新組回一行（`web/src/domain/lineAssembler.ts`）。
- 一般藍牙序列 App（例如 nRF Connect、Serial Bluetooth Terminal）也能直接連線、收發同樣的文字。
- 藍牙**沒有加密**：校正完成後，建議把 `firmware/RadarA_C4001_BLE/AppConfig.h` 的 `kAllowBleConfig` 改成 `false`，藍牙就只能讀資料、不能改設定（改設定要用 USB）。

## ESP32 → 網頁

### 遙測（每 0.2 秒；警示等級改變時立刻多送一筆）

```text
R=1 W=1 L=2 D=8.42 V=6.20 TTC=1.4 N=1 RD=8.50 RV=-6.31 E=52000 T=35 VS=2 RR=6.11
```

| 欄位 | 意義 | 單位／範圍 | 沒有資料時 |
| --- | --- | --- | --- |
| `R` | 雷達是否在線（ESP32 有收到 C4001 的資料） | 0／1 | — |
| `W` | 是否正在警示（`L` > 0） | 0／1 | — |
| `L` | 警示等級：0 安全、1 注意、2 危險 | 0～2 | — |
| `D` | 已確認來車的**追蹤距離**（濾波後） | m，2 位小數 | `-1` |
| `V` | 接近速度（正值 = 越來越近） | m/s | `0` |
| `TTC` | 到達時間 = 距離 ÷ 接近速度 | 秒，1 位小數 | `-1` |
| `N` | 雷達這一筆回報的目標數（C4001 最多 1 個） | 0／1 | — |
| `RD` | 雷達原始距離 | m | `-1` |
| `RV` | 雷達原始速度（正負號由雷達決定，見 `SIGN`） | m/s | `0` |
| `E` | 反射能量，最近 5 筆的中位數 | 整數 | `0` |
| `T` | ESP32 開機後經過的時間 | 秒 | — |
| `VS` | 速度來源（交叉核對結果，韌體 2.1 起）：0 沒有追蹤、1 核對中、2 都卜勒（已核對）、3 折疊已還原、4 改用距離變化率、5 正負號相反（請檢查 `SIGN`） | 0～5 | `0` |
| `RR` | 由最近 1 秒距離斜率算出的接近速度（正值 = 接近），對照用 | m/s | 不送 |
| `S` | **選用**：自身車速（預留給 Radar B） | km/h | 不送 |

### 設定回覆（回應 `GET`，以及每次設定成功後主動廣播）

```text
CFG TEST=1 MINSPD=1.50 MINE=0 RANGE=15.0 SIGN=-1 DTTC=1.5 DDIST=4.0 HOLD=1000 CONFIRM=3 FW=2.1.0
```

| 欄位 | 指令 | 意義 | 範圍 | 預設 |
| --- | --- | --- | --- | --- |
| `TEST` | `TEST 0\|1` | 室內測試模式：接近速度門檻暫時降為 0.1 m/s | 0／1 | 1 |
| `MINSPD` | `MINSPD <m/s>` | 接近速度門檻 | 0.05～10 | 1.5 |
| `MINE` | `MINE <整數>` | 反射能量門檻，0 = 不過濾 | 0～100000000 | 0 |
| `RANGE` | `RANGE <m>` | 警示距離 | 1～20 | 15 |
| `SIGN` | `SIGN -1\|0\|1` | 雷達速度哪個正負號代表接近；0 = 方向改由距離變化判斷 | -1／0／1 | -1 |
| `DTTC` | `DTTC <s>` | 危險到達時間：TTC 小於等於此值升級為危險 | 0.5～5 | 1.5 |
| `DDIST` | `DDIST <m>` | 危險距離：距離小於等於此值直接算危險 | 1～10 | 4 |
| `HOLD` | `HOLD <ms>` | 來車消失後警示保持時間 | 200～5000 | 1000 |
| `CONFIRM` | `CONFIRM <n>` | 確認來車需要累積的合格筆數 | 1～6 | 3 |
| `FW` | — | 韌體版本 | — | — |

設定存在 ESP32 的 NVS（命名空間 `radarA`），斷電不會消失。

### 指令回覆

| 回覆 | 時機 |
| --- | --- |
| `OK saved` | 設定成功並已存檔（接著會廣播一行 `CFG`） |
| `OK applied (flash save failed)` | 設定已生效，但寫入快閃記憶體失敗（重開機會還原） |
| `OK reboot` | 收到 `REBOOT`，約 0.2 秒後重新開機 |
| `OK commands: …` | `HELP` 或 `?` 的指令列表 |
| `ERR <原因>` | 數值超出範圍、格式錯誤等 |
| `ERR settings over Bluetooth are disabled, use USB` | `kAllowBleConfig = false` 時從藍牙改設定 |
| `ERR unknown command, try HELP` | 不認得的指令 |

## 網頁 → ESP32（指令）

一行一個指令，大小寫不拘，以 `\n` 結尾：

| 指令 | 作用 |
| --- | --- |
| `GET` | 回傳一行 `CFG` |
| `TEST 0\|1`、`MINSPD 1.5`、`MINE 50000`、`RANGE 15`、`SIGN -1`、`DTTC 1.5`、`DDIST 4`、`HOLD 1000`、`CONFIRM 3` | 修改單一參數（範圍見上表） |
| `DEFAULTS` | 全部參數恢復預設 |
| `REBOOT` | 重新啟動 ESP32 |
| `HELP` 或 `?` | 列出所有指令 |

## 解析規則（給要寫其他程式接收資料的人）

- 以空白切成 `鍵=值`；**不認得的鍵直接忽略**，所以之後可以安全地加新欄位。
- 同一行出現重複的鍵視為壞資料，整行丟掉。
- 數值一律用小數點、不含單位；`-1` 代表「沒有資料」（`D`、`TTC`、`RD`）。
- 以 `CFG` 開頭的是設定；以 `OK`／`ERR` 開頭的是指令回覆；其他含 `R`／`L`／`D` 的是遙測。

## 接上 Radar B（自身車速）

隊友的 Radar B 若接到同一顆 ESP32，只要在遙測行尾加上 `S=<km/h>`：

```text
R=1 W=0 L=0 D=-1.00 V=0.00 TTC=-1.0 N=0 RD=-1.00 RV=0.00 E=0 T=812 VS=0 S=18.5
```

網頁看到 `S` 就會在騎乘頁自動顯示「自身車速」，不需要改網頁。韌體的遙測緩衝區是 128 位元組（`kTelemetryLineMax`），目前最長一行約 105 位元組（含 `VS`、`RR`），加上 `S` 仍在範圍內。
